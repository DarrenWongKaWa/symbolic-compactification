# HTML_CONTRACT

V3.1: five visible layers. Less is more.

The page answers: **what does the physicist still need to judge?**
Machine-discharged material is quiet. Human-review obligations take
the strongest attention. One fact, one home.

1. Summary (title, `AUDIT_INCOMPLETE`, colour bar, one-sentence warning).
   Jump strip `#judge-strip` on the first screen: Need your judgment.
2. Coloured equation map (`#map-sec` before `#main`; `→` vs `⋯`).
3. Major claims (compact).
4. Central derivation (`from → to | operation | status`).
   Exact / Exact-if-A / structural / cited-rule edges collapse behind
   `✓ N machine-discharged steps`.
5. Reviewer queue (strongest visual weight; Source on each card;
   one Accept-warning).

Equation records and the full ledger are `<details>` drawers.
MathJax uses only `\(` `\)` / `\[` `\]`. No `$` delimiters.
`processEnvironments` is false so truncated inventory cues cannot auto-render.
Inventory cues are cleaned (align tabs stripped; `array` → `pmatrix`) then
wrapped in `\(` `\)`. If MathJax fails, show escaped `<pre class="tex-fallback">`.
Never drop an equation.

One disclaimer: `Local certification is not a paper-level certificate.`
One Accept-warning: `Human acceptance records reviewer judgment; it does not change a machine status to Exact.`
`Presentation is not a certificate.` must appear.
`#obligation-table` may exist inside a drawer for provenance.
