## Problem

Theoretical physicists routinely rewrite long symbolic derivations.
Computer-algebra systems and optional agents can **propose** a next
expression. Proposal is not evidence (L2). Heterogeneous moves
(algebra, substitution, declared rules, limits, remainders, definitions)
are easily collapsed into a single pass/fail bit.

## Method

One typed evidence graph supports two workflows (L1):

- Forward: untrusted candidate → typed claim → deterministic evidence →
  fail-closed promotion or refusal (L3, L5).
- Audit: printed equations → source-grounded relations → typed statuses →
  reviewer-facing table (L14, L15).

Claim type τ and certificate provenance c are independent axes (L6).
Engine `ZERO` is exact residual zero and is not a rule certificate (L4).
Substitution-conditioned zero is not unconditional equality (L7).
Core verification needs no model service and no API key (L10).

## Key semantic distinction

`ZERO` ≠ `CERTIFIED_BY_RULE`. `UNKNOWN` never promotes.
A generated verified table cannot be authored in Markdown (L8).

## Forward evidence

Public exact-step and refused-step demos (L11).

## Limitation

remainder certificate (L21). One named global rule in the present
catalogue (L23). Approximation-aware certification is Discussion-only
