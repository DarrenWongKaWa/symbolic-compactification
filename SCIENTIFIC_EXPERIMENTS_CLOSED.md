# Scientific Experiments Closed

The final Context-Grounded Verified Representation Discovery campaign is
**CLOSED** with `INSUFFICIENT_ADJUDICABLE_REAL_TASKS`.

The new protocol searched 11 candidates across seven scientific representation
families.  Only one fresh task had a source-grounded, assumption-complete,
leakage-controllable, operational evaluator.  The required minimum was three
tasks from three representation families.  Consequently, no model treatment,
baseline comparison, or context-effect estimate occurred.

## Supported claims

- Exact scalar verification and hash-bound session provenance operate on the
  supported parser input class.
- A source-derived rank-one Feshbach projected-resolvent task can be expressed
  as exact scalar obligations under declared rational-function domains.

## Rejected claims

- That this campaign measured a benefit from scientific context.
- That an LLM discovered a scientific representation in this campaign.
- That a scalar equality receipt is a general matrix, IBP, continued-fraction,
  or pole-map evaluator.
- That the unadmitted task count is a zero success rate.

## Unknown claims

- Whether context improves verified representation discovery on a valid
  multi-family corpus.
- Whether a structured evaluator for matrix blocks, IBP modules, continued
  fractions, or Lehmann maps would make such a corpus admissible.

## Engineering capabilities

The exact expression verifier, structural observation, session provenance, and
fail-closed `ZERO`/`NONZERO`/`UNKNOWN` semantics remain supported.  The release
posture is `INTERNAL_ONLY`; public paper/note ingestion and a public typed
context-hypothesis evaluation interface are not ready.
