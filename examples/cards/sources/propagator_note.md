# Note: a Fermi-weighted pair of broadened propagators

For a retarded and an advanced propagator with broadening G > 0,

  I(a, b) = ∫ dw nF(w) / ((w − a + iG)(w − b − iG)).

Closing the contour in both half planes gives

  I(a, b) = [iπ + ψ(z_−(b)) − ψ(z_+(a))]/(b − a + 2iG),

with z_±(x) = 1/2 + β(G ± ix)/(2π) and ψ the digamma function.
