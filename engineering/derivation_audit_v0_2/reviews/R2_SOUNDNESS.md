## Blocking findings

### B1. Reviewer package ships authored `TABLE_*.md` instead of regenerating from the exported run

`schema.may_appear_in_verified_table` / `schema.table_bucket` / `tables.generate_tables`
are the frozen inclusion authority, and they fail closed. The reviewer-facing
export does not use them when `reports/` already has markdown.

```176:200:src/symbolic_compactification/audit/package.py
def _ensure_reviewer_tables(
    workspace: AuditWorkspace,
    run: AuditRun,
) -> dict[str, Path]:
    reports = workspace.root / workspace.config.output_dir
    sources = {name: reports / name for name in _TABLE_MD_NAMES}
    missing = [
        name for name, path in sources.items()
        if path.is_symlink() or not path.is_file()
    ]
    if missing:
        artifacts = generate_tables(workspace, run)
        ...
    else:
        for name in (VERIFICATION_TABLE_JSON, VERIFICATION_TABLE_CSV):
            candidate = reports / name
            if candidate.is_file() and not candidate.is_symlink():
                sources[name] = candidate
```

`audit table` always overwrites from records. `audit package` copies whatever
regular files are already under `reports/`, including LLM-authored rows, banned
reviewer phrases, and tables from a *previous* run. `tests/test_audit_package.py`
locks this in (`test_generate_tables_is_called_only_when_reports_missing`,
`test_build_reviewer_package_writes_required_files` asserts authored
`verified-row\n` is preserved).

`reproduce.sh` re-runs `audit table` on `replay/`, which writes
`replay/reports/`. It does **not** refresh the package-root `TABLE_VERIFIED.md`
a reviewer actually opens.

This is a fail-open against:

- `LLM TEXT CAN NEVER CREATE VERIFIED STATUS`
- `VERIFIED TABLE IS GENERATED, NOT AUTHORED`
- `NONZERO` never hidden
- never labeled “the paper is wrong”

`tables._guard_public_text` only runs on generated bytes, so the copy path
bypasses it.

**Required fix (engineering only):** `_ensure_reviewer_tables` must always call
`generate_tables(workspace, run)` for the exported run, then copy those
artifacts. Do not treat pre-existing `reports/TABLE_*.md` as evidence. Drop or
invert the tests that preserve authored table bytes. Optional defense in depth:
refuse to package if a generated verified row is not `may_appear_in_verified_table`
on the exported records, or if a packaged `NONZERO` record is absent from
`TABLE_NONZERO.md`.

## Kernel checks that are *not* blockers

These six assigned properties hold in `schema.py` / `lowering.py` /
`evidence.py` / `tables.py` / Demo C. They are not sufficient for alpha while
B1 remains.

1. **LLM text cannot create ZERO in generated tables.**
   `may_appear_in_verified_table` requires `integrity_ok`, `status == result == ZERO`,
   `executable`, and excludes `SPLIT_PARENT` and `ASYMPTOTIC_CLAIM`.
   `tables.bucket_records` double-gates on that predicate. Forged markdown is
   ignored on `audit table` regeneration (`tests/test_audit_tables.py`,
   `tests/test_audit_adversarial.py`, release-critical Demo C restore test).

2. **Finite Laurent coefficients ≠ remainder proof.**
   `ASYMPTOTIC_CLAIM` is `_NEVER_EXECUTABLE_TYPES`. Integrity rejects
   `result==ZERO` without `remainder_certificate_hash`. Evidence always stores
   `remainder_certificate_hash=None` and downgrades a hypothetical engine ZERO
   to `UNKNOWN`. Even a well-formed remainder hash cannot enter
   `TABLE_VERIFIED` (`may_appear_in_verified_table` excludes the type). Demo C
   parent stays `UNKNOWN` while coefficient children are `ZERO`.

3. **SPLIT parent is never engine ZERO.**
   Adjudication returns `SPLIT` without calling the verifier.
   `derive_split_parent_status` returns only `SPLIT` or `CERTIFIED_BY_CHILDREN`.
   Missing / integrity-fail / non-ZERO children block certification.
   `public_status_label(CERTIFIED_BY_CHILDREN)` is `SPLIT — all children certified`
   and does not contain `ZERO`. Markdown Result cells use that label.

4. **NONZERO is not dropped by table generation.**
   Integrity-ok `NONZERO` buckets to `TABLE_NONZERO`. Generated markdown title
   is `POTENTIAL DERIVATION MISMATCHES` with `NONZERO_REVIEWER_TEXT`. Deleting
   the file and regenerating restores it. B1 is the path that can hide it.

5. **Evidence hashes bind source + residual + assumptions + verifier.**
   `bind_hashes` obligation payload includes `source_snapshot_hash`,
   `residual_hash` / lhs / rhs, `assumptions_hash`, `declared_assumptions`,
   `verifier_route`, `engine_version`, `edge_id`, `edge_type`. Changing residual
   bytes, assumptions, snapshot, route, or engine yields a new `obligation_hash`.
   Runs are exclusive and never overwritten. `_seal` rewrites illegal ZERO to
   `INVALID_RECORD`.

6. **Lowering does not rewrite `F - A/gamma = 0`.**
   Asymptotic / integral / split / definition / bookkeeping never become a
   local residual. Demo C does not attach lhs/rhs/residual on the remainder
   edge. See non-blocking N1 for the evidence-layer residual-*text* leak.

## Non-blocking (do not expand alpha to close these)

Allowed limitations remain: no remainder-certificate production path, integral
arguments not local residuals, `real:false` rejected, manual transcription.

- **N1.** If an `ASYMPTOTIC_CLAIM` supplies lhs/rhs files and no residual,
  `adjudicate_lowered_edge` still *stores* `({lhs}) - ({rhs})` as
  `residual_text` / hash while leaving `executable=False` and `UNKNOWN`.
  Observed: `(a/g + b*g) - (a/g)`. That is not a ZERO and does not enter
  `TABLE_VERIFIED`. It can still look like an exact-identity residual in
  `TABLE_UNCERTIFIED`. Demo C does not hit this. Fix later: do not construct
  or persist a native difference for `_NEVER_EXECUTABLE_TYPES`.
- **N2.** `NON_RESIDUAL_CLAIM_TYPES` is unused. `LIMIT_CLAIM` may execute a
  *supplied* residual (documented PARTIAL). Naked lhs/rhs limits are not
  rewritten. Type misuse remains a transcription residual risk.
- **N3.** `load_audit_run` checks hash *format*, not that `obligation_hash`
  equals `bind_hashes(...)` of current bytes, and does not re-verify. The
  threat model’s stated control is “forged ZERO without hashes”. Exclusive
  run writes keep this inside the evidence TCB; B1 is the export hole.
- **N4.** Optional HTML Result column prints raw `record.result`. Production
  split parents never have engine `ZERO`. HTML is non-blocking per the
  interface freeze.
