# Failure taxonomy (LLM abstraction DEV)

| class | meaning |
|---|---|
| PARSE_FAILURE | output is not schema-valid; not silently repaired |
| ABSTAIN | model declined to propose (valid on negatives) |
| UNNECESSARY_STRUCTURE | interpolation/geometry/latent-space not demanded by the expression |
| shallow | hole-product / trivial LGG treated as a scientific object |
| tautological | latent object is a rename of one member |
| incorrect | wrong type or wrong members |
| unverifiable | constructor/engine cannot test the claim (`UNKNOWN`) |
| gold-like-but-unsupported | type+members look right but obligations are not ZERO |
| false_abstraction | certified (or strongly asserted) structure on a negative |
| anchoring_to_CSE | SOL packets pull the model into local CSE/LGG and away from F5/F6 |
| BLOCKED | no key / API error; not a scientific negative |

Verbal mention of a master function is not success.
Certified `ZERO` on stated obligations is the only exact truth.
