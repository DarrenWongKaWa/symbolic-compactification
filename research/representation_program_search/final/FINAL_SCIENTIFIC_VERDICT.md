# Final Scientific Verdict — Verified Representation Program Search

Status: **CLOSED AT THE MANDATORY PRE-TREATMENT DEV GATE**

This experiment started from, and does not reinterpret, the preceding
Publication F result at `0cdde498715f1e1bb146ff33c8c90350077352ca`.
It implemented a formal representation-program language and auditable search
machinery, but the scientific comparison never began. The required fresh DEV
calibration suite could not be assembled from the bounded audited candidate
set under the frozen parser/IR, freshness, assumption, leakage, and admission
rules. Consequently no S0–S7 or F0 scientific condition ran, no live LLM call
occurred, no TEST was frozen, and no causal method effect is estimable.

This is a pre-treatment feasibility closure. It is not evidence that an
enumerative, symbolic, SOL-guided, verifier-guided, or LLM-guided search
algorithm was run and failed.

## 1. Why free-form proposal was replaced

The previous experiment found cluster-local R2 resolvent construction but no
held-out operational AI advantage, no certified R3+, and increased
terminology/tautology under specialist prompting. The new hypothesis therefore
changed the mechanism under study: a representation became a typed program of
latent objects, operators, explicit node multiplicities, member assignments,
and reconstruction obligations. LLMs, if evaluated, would only rank legal
states or legal next actions. Exact verification remained the hard gate.

## 3. Representation grammar

`RepresentationGrammarV1` was frozen before case evaluation. It includes the
declared latent-object forms, explicit repeated-node structures, and the
operators `VALUE`, `SUBSTITUTE`, `DERIVATIVE`, `SHIFT`, `PERMUTE`,
`NEWTON_DD`, `HERMITE_DD`, `RECURRENCE`, `LINEAR_COMBINATION`,
`BASIS_PROJECT`, `BASIS_RECONSTRUCT`, and `COMPOSE`. Optional later operators
were not added. A contract-access correction exposed `COMPOSE` through the
legal action set without changing the mathematical grammar.

The grammar is implemented and typed. It has not been scientifically shown to
discover a representation.


and four source-grounded two-node Newton divided differences followed by exact
member-specific linear factors. All four obligations were ZERO under
`G_FULL`, `G_NO_HERMITE`, and `G_PRIMITIVE`: 12 stored ZERO receipts, followed
by 12 independent ZERO replays. The exact canonical program id is
`0002761432e0bd2c6c0ea2050622b287ea817d00769555c30a08ee3022dd5b66`.

This establishes an exact, non-tautological R2 calibration object. It does not
measure R2 search performance because no method searched for it.

Q7V3 is the strongest counterexample to equating exactness with scientific

construction—yet fails freshness and source-member admissibility because it is
an author-constructed scalarization of a historical TEST superfamily. Exact
verification is necessary, not sufficient, for benchmark evidence.
