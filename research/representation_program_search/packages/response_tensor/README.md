# Response/tensor machine packages

These packages are admission evidence for fixed scalar or fixed-index instances
under the frozen parser. They are not benchmark partitions and do not change the
grammar, parser, verifier, or scientific dossiers.

`PACKAGE_READY` means that the package's exact, explicitly bounded obligations
have a retained ZERO session. For finite-index tensor lowerings it does **not**
mean that a symbolic-dimension tensor identity has been proved.

The only proposer-facing object is `proposer_view.json`. Reference programs,
operator roles, audited depth, obligation tags, and source-role annotations are
evaluator-only.
