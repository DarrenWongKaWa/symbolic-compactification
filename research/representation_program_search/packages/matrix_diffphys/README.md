# Matrix and differentiable-physics machine packages

These are fixed scalar or fixed-dimension lowerings of fresh C1/C5 dossiers.
They are not benchmark partitions and they do not prove identities at symbolic
matrix dimension.  Every `PACKAGE_READY` package has a complete
`RPSCasePackageV1` manifest and exact-ZERO session evidence for each required
obligation.

The oscillator package is intentionally `PROOF_REQUIRED`: its original
complex-domain reconstruction retains one required UNKNOWN. A narrower
real-domain ZERO replay is preserved as diagnostic evidence but is ineligible
for certification.

The proposer projection is deliberately limited to the SHA-bound source
catalog and the scientific assumption contract.  Representation depth,
operator sequences, reference programs, obligation candidates, and source
roles remain evaluator-only.

Validate the tree with:

```bash
python3 -m research.representation_program_search.packages.matrix_diffphys.validate
```
