# Success definitions

## PROGRAM_SUCCESS

Complete grammar program; grounded members; explicit operators;
complete assumptions; compile; all required obligations ZERO;
non-tautological; no target leakage.

## AI_SEARCH_ADVANTAGE

Matched state budget: LLM-guided PROGRAM_SUCCESS and deterministic /
symbolic / random search do not; replicated. Confirmed only after
auditors A/B/C all PASS.

## GRAMMAR_ADVANTAGE

Deterministic program search succeeds where free-form LLM and frozen
symbolic stack failed. Not an AI result.

## PROBLEM_UNDERSPECIFIED

Required analytic-domain predicate NOT_DECLARED. Not a method failure.

## PACKAGING_GAP

Frozen parser cannot ingest the object. Not method superiority.

## Remainder invariant

neg ZERO + C0 ZERO + remainder UNKNOWN ⇒ UNKNOWN, never ZERO.
