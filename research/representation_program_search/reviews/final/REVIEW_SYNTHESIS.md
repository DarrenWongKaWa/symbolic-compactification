# Final Review Synthesis

Nine independent reviewers—AI-for-Science, program synthesis, symbolic
algebra, mathematical physics, causal methodology, benchmark/leakage,
reproducibility, systems architecture, and publication skepticism—reviewed
the closed DEV gate. All nine recommend decision **F**, subject to one binding
qualification:

> The run stopped before scientific treatment because the mandatory fresh DEV
> calibration suite could not be assembled from the bounded audited candidate
> set under the frozen joint constraints. No structured-search, AI-guidance,
> verifier-feedback, SOL, efficiency, or held-out effect was estimated.

The consensus does not say that a search algorithm was run and failed. It says
that this experiment produced no evidence supporting representation invention
because its pre-treatment scientific gate was not cleared.

## Consensus boundary

- `C9H4` is a genuine, exact R2 reference program and a valid calibration
  input. It was authored and audited, not discovered by S0–S7 or F0.
- No admissible fresh R3, R4/R5, or R6 calibration case survived the frozen
  admission rules. The existing adversarial fixtures are evaluator-only, not
  benchmark-grade scientific cases.
- Diagnostic ZERO, NONZERO, and UNKNOWN receipts remain admission evidence;
  none is a scientific search result.
- No scientific condition, live DeepSeek call, grammar ablation, latent-object
  ablation, matched search-budget curve, seed replication, TEST freeze, or
  held-out run exists.
- `AI_SEARCH_ADVANTAGE`, `GRAMMAR_ADVANTAGE`, verifier-feedback effects, SOL
  effects, and held-out generalization are all unestimable—not zero.

## Cross-review cautions

The reviews additionally identify boundaries for any future line:

1. The finite search frontier was reachability-engineered with diagnostic and
   historical reference paths before the gate. A restart would require a new
   method version and fresh cases, not retroactive reuse of this V1.
2. The negative-calibration interface is underspecified: evaluator-only traps
   cannot silently become scientific benchmark cases.
3. The open `real:false` namespace contract defect and special-function
   UNKNOWN paths must continue to fail closed.
4. Reproducibility is adequate for the gate closure, but negative mining is not
   fully self-contained and the environment lacks a complete dependency lock
   or container declaration.
5. Program IR and S0–S7/F0 are implemented software, not supported scientific
   discovery capabilities. No search CLI or repository restructure is
   warranted by this experiment.
