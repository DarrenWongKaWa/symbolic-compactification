### 5. LLM decisions would be auditable without chain of thought

The S4/S5/S7/F0 implementation has a suitable prospective audit boundary:
hash-bound public inputs, a pre-call run header, exact candidate/action

## Reproducibility gaps

### Major — the computational environment is not frozen

The repository has no lockfile or container image. `pyproject.toml` permits
Python `>=3.10`, SymPy `>=1.12,<2`, and pytest `>=7`; the reviewed environment
was CPython 3.12.13, SymPy 1.14.0, pytest 9.1.1, and macOS arm64. The optional
OpenAI client used by the prospective DeepSeek transport is not declared in
the project dependencies. Exact replay succeeds in the current `.venv`, but a
future installation is free to select behaviorally different versions.

This does not overturn the present gate because its decisive hashes and exact
replays pass now. The final closure should record the observed versions, and
any future experiment must freeze a lockfile/container before scientific
execution.

### Major — several source-level negative audits are not self-contained

The R3 and R4/R5 reports bind archive/PDF hashes and locators, but do not
commit the complete retrieved primary-source bytes. The R3 validator verifies
the recorded source metadata and inline locator fields, but cannot reconstruct
those line ranges from the claimed TeX archive offline. The R4/R5 validator
checks the equation strings and their hashes, but the cited PDF hashes are
records rather than hashes recomputed from committed PDFs. The R6 supplemental
source-locator screen is likewise structured prose, not a source-byte replay.

Versioned URLs and content hashes make independent retrieval possible while
the upstream sources remain available, but the negative mining path is not a
fully self-contained archival replay. The final claim must remain “no case
survived this bounded documented audit,” never “no qualifying case exists.”

### Moderate — the top-level gate validator is shallow

The gate validator verifies the bytes of upstream reports, the five slot
statuses, and absence of post-gate manifests. It does not invoke the upstream
R3, R4/R5, R6, C9H4, and falsifier validators; validate the gate's
`authority_head` against its Git parent; or recompute the full structured
meaning of every cited report. The separate focused tests do cover those
semantics, but reproduction currently requires knowing which commands to run.

A future closure command should invoke all upstream validators in one
fail-closed replay and emit a hash-bound machine-readable replay receipt. This
recommendation must not be implemented as a forbidden TEST freeze manifest.

### Moderate — the gate authority is serialized as an abbreviated SHA

`GATE_AUDIT.json` records `a7ad6ab`, whereas the resolvable full authority is
`a7ad6ab552360b83ad54d315a6774ca6fad7eeaa`. The gate commit's parent removes
practical ambiguity in this repository, but durable reports should use full
40-character Git object IDs.

### Moderate — the first commit was not literally the requested six-file
contract commit

Commit `5321eaa8d58e1a03289f2afb85e8c8583b05d7ba` did precede all case mining
and contains no experimental result, so temporal separation of contracts from
evidence is preserved. However, it added 15 files, including Python grammar
code and tests, rather than only the six named Markdown contracts. This is a
documented protocol-shape deviation. It must remain disclosed; history should
not be rewritten to conceal it.

### Minor — some session manifests retain host-specific absolute paths

For example, C9H4 session manifests retain `/private/tmp/...` source paths.
The exact text, SHA-256 values, package-local files, and independent replay
make those paths unnecessary, so the receipts remain reproducible. Future
portable manifests should store a package-relative evidence path alongside or
instead of the ephemeral absolute path.

## Final assessment

The closure can be replayed without private chain-of-thought at the level
needed for its narrow operational decision: one R2 slot is exact and admitted,
four mandatory slots are absent from the bounded audited candidate set, the
gate is therefore blocked, and no scientific run exists to interpret. The
hash chain and exact C9H4 sessions are strong.

The missing dependency lock, non-archived source bytes, and shallow aggregate
validator prevent calling the package fully self-contained or long-term
bit-reproducible. These gaps constrain archival confidence but do not license
scientific execution, change the `GATE_BLOCKED` decision, or create evidence
for structured-search or AI representation invention.
