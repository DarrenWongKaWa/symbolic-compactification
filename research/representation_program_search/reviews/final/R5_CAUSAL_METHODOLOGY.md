# R5 Final Review — Causal Methodology

## Review decision

**The `GATE_BLOCKED` closure is causally correct, but it is a pre-treatment
feasibility closure, not a null result for structured search.** No planned
causal comparison, search-efficiency contrast, AI-specific advantage,
grammar advantage, verifier-feedback effect, SOL effect, or generalization
effect is estimable from this experiment. The admissible evidence supports
only a bounded process result: this run did not assemble its mandatory first
DEV calibration suite under the frozen scientific-language, freshness,
leakage, assumption, and admission constraints, so it correctly executed no
scientific search and froze no TEST.

Recommended publication decision: **F — STRUCTURED SEARCH ALSO FAILS TO
SUPPORT REPRESENTATION INVENTION**, with the required qualifier that “fails
to support” means **no evidentiary test was reached**, not that any structured
search algorithm was run and failed.

## First DEV gate assessment

The frozen first gate required one independently admitted R2 case, one R3
case, one R4/R5 case, one R6 case, and one negative trap before all methods
could execute. The evidence at closure was:

| required slot | admissible evidence | causal disposition |
|---|---|---|
| R2 | `C9H4` independently admitted, with 12 stored and 12 independently replayed ZERO obligations across the three grammar variants | Ready only as a DEV R2 calibration input; it was never a search treatment observation and says nothing about discovery. |
| R3 | no retained case after a bounded three-family fresh-source and historical-superfamily audit | Missing. This is a bounded mining/admission result, not a claim that scientific R3 cases do not exist. |
| R4/R5 | no retained case after two strict scientific leads; surviving formulas were old-TEST variants, unsound on the frozen domain, verifier-UNKNOWN, or outside the frozen package boundary | Missing. Diagnostic ZERO/NONZERO/UNKNOWN sessions are package-screening evidence, not method outcomes. |
| R6 | zero qualifiers in the bound registry; most nominal R6 dossiers were packaging gaps and executable lowerings collapsed below R6 | Missing. This locates a joint scientific-IR/package/admission bottleneck but does not isolate a causal effect of grammar, parser, or search. |
| negative trap | six synthetic evaluator-only falsifier fixtures | The final gate treated the scientific calibration slot as missing because the fixtures are benchmark-inadmissible. Even if “negative trap” were interpreted more permissively and one fixture were accepted for software calibration, R3, R4/R5, and R6 would still be missing; the `GATE_BLOCKED` conclusion is therefore robust to this ambiguity. |

The decision not to substitute diagnostics, historical TEST cases,
fixed-instance scalarizations, packaging gaps, or evaluator-only fixtures for
missing scientific depth slots preserves the original estimand. Weakening
the gate would have changed the population and representation-depth target
after seeing candidate failures.

The gate report's phrase “operationally infeasible” must be read narrowly.
The evidence proves **not constructed in this bounded run from the audited
registry under the frozen joint constraints**. It does not prove that no
admissible suite exists, that additional independent mining could never find
one, or that the grammar/parser alone caused the failure.

## Design-provenance limitation if this line were resumed

Before the mandatory calibration gate, `d483767` amended the finite search
policy after legal-path checks on `rps-real-c8q2` and `rps-real-c3j9`, and its
tests explicitly construct complete reference paths. Those cases were later
classified respectively as an R1 diagnostic and an old-TEST structural
variant. The amendment is transparently versioned and does not invalidate
the present no-run closure. It would, however, prevent a future resumed V1
from treating those cases or close structural relatives as untouched method
evaluation evidence. Any restart would need a new predeclared method version,
fresh admissible cases not used in reachability engineering, and a new first
gate; it must not retroactively call the present implementation semantics
empirically frozen.

## Supported and forbidden causal claims

Supported:

1. The contracts and software paths for S0–S7/F0 were implemented and tested
   as software, subject to their documented incompleteness and matching
   requirements.
2. One non-tautological R2 scientific identity (`C9H4`) cleared independent
   admission for DEV calibration, but was not searched.
3. This bounded run retained no admissible R3, R4/R5, or R6 calibration case,
   and the full mandatory suite was not assembled.
4. The fail-closed gate prevented post hoc substitution, scientific method
   runs, live LLM calls, TEST freeze, and method interpretation.
5. The experiment therefore provides no new evidence supporting formal
   representation-program search or an AI heuristic advantage.

Forbidden:

1. Any claim that S0–S7 or F0 succeeded, failed, tied, or differed in
   efficiency.
2. Any `AI_SEARCH_ADVANTAGE`, `GRAMMAR_ADVANTAGE`, verifier-effect, SOL-effect,
   primitive-composition, or latent-induction claim.
3. Any held-out or cross-model generalization claim.
4. Any assertion that structured search itself was empirically falsified.
5. Any universal claim that R3/R4/R5/R6 cases cannot exist under the grammar
   or that parser/IR limitations alone caused the gate failure.
6. Any use of diagnostic ZERO receipts as search-discovery outcomes.

## Publication recommendation

Choose exactly **F — STRUCTURED SEARCH ALSO FAILS TO SUPPORT REPRESENTATION
INVENTION**.

A–D all require method or system capability evidence that was never
generated. E includes the affirmative word “promising,” which is also not
supported by an admitted-suite search result. F is the only available label
consistent with zero supporting evidence, provided the report states the
causal qualifier prominently:

> The program-search hypothesis was not experimentally adjudicated. The run
> stopped before treatment because the mandatory fresh scientific calibration
> suite could not be assembled from the bounded audited candidate set under
> the frozen joint constraints. Therefore no structured-search, AI-guidance,
> verifier-feedback, SOL, efficiency, or generalization effect is estimated.

This is a scientifically useful negative process result about benchmark and
scientific-IR feasibility. It is not an efficacy result for representation
program search.
