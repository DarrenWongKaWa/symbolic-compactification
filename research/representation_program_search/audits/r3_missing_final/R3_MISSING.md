# Final bounded fresh-R3 mining audit

## Verdict

`R3_MISSING`. No candidate package was created.

Three real primary-source families were screened against criteria frozen before
promotion: the source itself had to display a multi-member scientific catalog,
state a sufficient real domain, expose an operational repeated-node R3 target,
remain fresh against every historical/current case, and permit a proposer
surface without target/operator leakage. A candidate selected merely because a
paper names the same operator as the grammar was ineligible.

## Strongest near-miss

Rosiek's MassToMI paper (`arXiv:1509.05030v2`, DOI
`10.1016/j.cpc.2015.12.011`) supplies the strongest displayed catalog. Its
TeX lines 1286–1354 show distinct, partially repeated, fully repeated, and
mixed-argument `b21` expansions. The mixed example has a threefold repeated
first coordinate followed by a first difference in the second coordinate.

It is not admissible. The paper and API explicitly label the objects as
divided differences, so the representation is supplied before search. The
univariate rows are instances of historical TEST superfamily
`mp-opitz-dd-01` and historical Hermite matrix-function case
`mp-hermite-fA-01`. The scalar API example also does not locally state all
real-domain predicates needed for a strict public case. Promoting only the
mixed row would turn a named source API construction found via grammar terms
into a circular “invention” benchmark.

## Other serious screens

Rubensson (`arXiv:2306.15814v1`, DOI `10.1137/23M1580589`) gives an explicit
real-Hermitian density-matrix setting, a spectral gap, and a source-displayed
first-/second-order catalog. Repeated occupied or virtual eigenvalues yield an
R3 confluence. It is nevertheless a direct instance of the old arbitrary-node
Opitz/Hermite families, close to the old Daleckii–Krein family, and it remains
the old arity-three/two-stratum pattern.

Dedes et al. (`arXiv:1504.00960v2`, DOI
`10.1007/JHEP06(2015)151`) display the physical `B0/C0/D0` insertion catalog
and explicitly state real non-negative diagonal squared masses. But the
concrete scientific catalog does not display a repeated-node R3 family. R3
appears only in the generic FET divided-difference theorem and degeneracy note.
Selecting that stratum would again select the task for the named grammar
operator, and the theorem is already generically covered by historical cases.

## Duplicate boundary

The baseline inventory covered 117 historical/current JSON artifacts at
authority head `bcb43e25c0b529fcf172d545e852577848d2135c`; their sorted
path/hash inventory is bound in `R3_MISSING.json`. Metadata were scanned across
that inventory, while the JSON separately identifies the seven controls that
received manual semantic comparison. The decisive frozen control is previous
TEST CHALLENGE case `mp-opitz-dd-01`: arbitrary nodes, explicitly not
necessarily distinct, with Hermite jets for nonpolynomial functions. A new
scientific function or a new multiplicity partition does not escape this
generic identity.

Q7V3 and C3J9 were used only as current proximity controls. This pass did not
reuse their benchmark-author constructions and did not inspect any hidden TEST
program or evaluator label.

## Scientific boundary

The negative result does not say that no real scientific R3 identities exist.
It says this bounded pass found no case satisfying all admission constraints at
once. Relaxing freshness, concealing a source-supplied operator, inferring a
domain, or authoring scalar members from a theorem would manufacture a case and
violate the experiment contract.

No grammar, search, parser, verifier, shared manifest, TEST artifact, or method
implementation was changed. No verifier or search method was run.
