# Layer map

Closed observation×LLM work showed that L3-looking failures were sometimes L4.

```
L0  exact verifier          ZERO / NONZERO / UNKNOWN
L1  structural observation  SOL v1 (frozen 0a2905b)
L2  typed hypothesis        DeepSeek proposer (frozen protocol)
L3  representation search   Track A  (open)
L4  obligation compilation  Track B  (open; measure first)
L5  scientific interpretation  still forbidden in preprocessing
```

L3 searches a **representation class**, not a final formula.
L4 compiles hypotheses into a **Scientific Proof Obligation IR**.
L5 names physical objects; it has no promotion authority.

Track A and Track B must not be mixed in one patch or one metric.

If a frozen raw output goes UNKNOWN → ZERO under a new compiler,
that is **C/L4 gain**, not discovery gain.
Discovery gain requires a new hypothesis type that the frozen
output did not contain.
