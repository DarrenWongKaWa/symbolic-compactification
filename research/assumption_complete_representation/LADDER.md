# Representation ladder (independent of Guo)

| level | name |
|---|---|
| R0 | exact repeated local structure |
| R1 | parameterized family |
| R2 | first Newton DD |
| R3 | repeated-node / Hermite DD |
| R4 | Piecewise / degeneracy unification |
| R5 | special-function representation |
| R6 | multi-operator master object |
| R7 | small master library |
| R8 | invariant / generator representation |

A task may stop below R8. Naming a type is not reaching the level.
`SCIENTIFIC_DD_OK` and `SCIENTIFIC_MASTER_OK` are defined in
`SUCCESS.md`.
