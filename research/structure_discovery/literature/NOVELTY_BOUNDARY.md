# Novelty boundary — scientific structure discovery

Date: 2026-08-27.

This is a positioning contract. Closest works are real. “We found no prior
work” is forbidden. Title mismatch is not novelty.

## The triple under test

```
abstraction invention  +  already-exact scientific expressions  +  exact verification
```

## Already done (do not claim)

1. Untrusted proposer + trusted checker (FunSearch, AlphaGeometry, LGuess, ToRA, Method v2).
2. Inventing reusable abstractions over *programs* (DreamCoder, Stitch, babble, Szalinski).
3. Discovering formulas / invariants / Lie groups from *data* (AI Feynman, SINDy, AI Poincaré, LieGAN).
4. Exact compactification of physics algebra by domain CAS (FORM, Cadabra, xAct, IBP).
5. LLM-guided equality saturation on *polynomials* (LGuess).
6. Fail-closed residual adjudication on scientific expressions (this repo, engine 0.3.0 / Method v2).

## What would actually be new

A system that, given an already-exact theoretical-physics expression:

- proposes a *typed* structural hypothesis (kernel / orbit / master /
  divided difference / generator) that is not merely a shorter AST;
- constructs an explicit reconstruction;
- retains it only on exact ZERO;
- and that this helps a physicist continue a derivation.

That combination is **not** covered by any single closest paper. It is a
*recombination* of library-learning ideas with a scientific residual gate.

## What this line must not write

- “First LLM + verifier.”
- “We beat Mathematica at simplification.”
- “We discovered new physics.”
- “Named auxiliary ⇒ discovery” (Method v2 already showed tautological names).
- “Scientific compactness = count_ops.”
- DreamCoder novelty by renaming library learning as structure discovery.

## Novelty that would survive review

Only with evidence:

| Claim | Dies if |
|---|---|
| Typed H are proposed more often than CAS/direct LLM | B1/B6 match gold types at the same rate |
| Decomposition E→H→E' beats E→E' on D3–D5 | no D3–D5 gap |
| Aggressive H can be searched because UNKNOWN/NONZERO block them | any false ZERO on a forbidden merge |
| Discovered structure helps downstream physics | no utility signal, only prettier names |

Until those experiments exist, the contribution is a **problem formulation +
benchmark + negative/partial result**, not a method SOTA.
