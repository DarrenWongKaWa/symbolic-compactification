# Scope

## In scope

- Typed structural hypotheses on exact expressions.
- Deterministic observations (facts only).
- Construction of closed reconstructions.
- Fail-closed residual verification (engine 0.3.0, unchanged).
- Positive and negative structure-discovery tasks.
- DEV case study on Guo σ_abc (not held-out evidence).

## Out of scope

- Beating CAS on `count_ops`.
- Formal Lean/Isabelle proofs.
- New physics.
- Universal theorem proving.
- LLM multi-model tables (blocked: no usable API keys in this environment).
- Using Guo as test evidence.
- Encoding gold names into scientific_context.

## Division of labor

| Role | Owns |

| Human physicist | meaning, assumptions, D6 usefulness |

| Verifier | ZERO / NONZERO / UNKNOWN |

## Certification language

ZERO means exact under declared SymPy engine semantics, not a formal proof.
