# Research cases (not the product)

These directories are historical paper audits and long physics fixtures.
They are **not** loaded by the installed Skill, not used by default CI,
and not an answer key for a new task.

Default product demos:

- `examples/forward/`
- `examples/audit/minimal/`

Replay (optional):

```bash
pytest research-cases/test_v3_2604_audit.py
pytest research-cases/test_flagship_html.py
```
